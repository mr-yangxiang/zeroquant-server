## 前轮修复摘要

- 凭据限流覆盖大小写及尾斜杠路径变体。
- 公共逐笔导入先整批验证，再加锁原子替换；插入失败回滚旧快照。
- 聊天只接受明确、完整、单笔成交陈述，不猜价格或默认 1000 股。
- 旧请求不能用新账号的令牌重试，旧响应不能在切换身份后覆盖页面。
- Web Locks 类型修复，前端构建前置 TS 检查；Node 日志脱敏、LLM 超时、子进程输出上限。
- 弱密钥占位值拒绝；无效供应商时间拒绝；Python provider/outbox 不写凭据异常；构建上下文排除敏感文件。

```bash
python3 scripts/review_inventory.py

```

--check 会核对 80 项完整编号、证据文件摘要/锚点/行号、两仓库文件集合与审查快照。代码变化使旧证据失效时应重新审查；禁止只改摘要而继续沿用未经核实的“通读”结论。
